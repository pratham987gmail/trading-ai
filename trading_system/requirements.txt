# ===========================================================================
#  DELIBERATELY NOT DEPENDENCIES
# ===========================================================================
# No technical-analysis library is used. Phase 3 (analysis/) implements its
# indicators directly, for two reasons:
#
#   pandas-ta==0.3.14b0   Imports `numpy.NaN`, which numpy removed in 2.0. It
#                         cannot import against the numpy pinned above, and
#                         adopting it would mean pinning numpy < 2.0 and
#                         dragging pandas back with it. Upstream issue #857 is
#                         still open.
#
#   TA-Lib==0.4.32        Requires the C library to be compiled and installed
#                         before the wheel will build. A poor trade for
#                         indicators that are twenty lines of pandas each.
#
# The deciding reason is architectural rather than either of those. Both
# libraries are whole-frame and vectorised, but the backtest engine consults a
# strategy once per bar, so a whole-frame indicator is recomputed from scratch
# on every call. The MarketView accessors compute over a bounded trailing
# window instead, which is what keeps a 9,500-bar run at seconds.
#
# Option chain storage uses the stdlib `sqlite3` module, so no SQLAlchemy or
# aiosqlite dependency is needed for Phase 2.5 either.
#
