# Predictive-value study: does FII/DII/client positioning predict NIFTY's forward return?

Generated by `research/ml/fii_dii_positioning_study.py`. Full output:
`fii_dii_positioning_NIFTY.json`.

## A genuinely different information source

Every prior study measured something about the option chain itself
(price action, PCR/OI change, max pain). This study is the first to pull
from outside `data/option_chains.db` entirely: NSE's own daily
"Participant wise Open Interest in Equity Derivatives" archive
(`nsearchives.nseindia.com/content/nsccl/fao_participant_oi_*.csv`),
confirmed to cover this project's full analysis window back to September
2024. 357 daily files downloaded and cached in `data/fii_dii_oi/`
(commonly cited data used by retail commentary as "FII/DII/client
positioning").

Six features from the FII, DII, and Client (retail) index-futures and
index-options net positioning: `fii_index_fut_net`,
`fii_index_fut_net_change_1d`, `fii_call_minus_put_long`,
`client_index_fut_net`, `client_index_fut_net_change_1d`,
`dii_index_fut_net`. Same discipline as every prior study: purged
walk-forward validation, two classifiers, verdict compared against each
fold's own majority-class baseline.

## Verdict: still no edge — but the closest of five studies to one

| | |
|---|---|
| Trading days usable | 351 (2 years, joined against real spot closes — no gap-filling) |
| Folds evaluated | 7 |
| **Folds clearing 55% accuracy** | **1 of 7** (14.3% — well under the 70% required) |
| Folds beating their own majority baseline | **5 of 7 (71.4%)** — the highest of any study so far |
| Best single fold | 58.97% (fold 5, RandomForest) |
| Worst single fold | 20.5%–23.1% (fold 7) |

**This is honestly the most promising-looking result of the five studies
run in this project**, and it is still not evidence of a real edge. One
fold in seven clearing an accuracy bar is well within what plain noise
produces — with no real signal at all, you would expect roughly one
fold in twenty to exceed 55% by chance under repeated testing, and
getting one in seven is not a meaningfully rare event. The "beats
baseline" rate (71.4%) is a softer, easier bar (it does not require
beating 55%, only beating whatever that fold's own naive guess was), and
is not itself evidence of exploitable skill — several of "beats
baseline" folds still scored well under 50% accuracy in absolute terms
(fold 1: 43.6%, fold 6: 35.9%).

**Verdict: `NO_PREDICTIVE_VALUE_FOUND`**, by the same fixed criteria
every other study in this project was held to (≥70% of folds clearing
55% accuracy). Reporting fold 5 honestly rather than either hiding it or
overselling it: it is a data point, not a discovery.

| Feature | Importance |
|---|---|
| `dii_index_fut_net` | 25.8% |
| `fii_call_minus_put_long` | 18.6% |
| `fii_index_fut_net` | 15.2% |
| `client_index_fut_net` | 14.8% |
| `fii_index_fut_net_change_1d` | 13.3% |
| `client_index_fut_net_change_1d` | 12.4% |

Domestic institutional (DII) net futures positioning ranked highest, not
FII (the more commonly discussed "smart money" signal) or Client
(the commonly cited contrarian signal). Worth flagging as a candidate for
a more targeted follow-up rather than a conclusion on its own — the same
"highest-ranked among features that collectively don't clear the bar"
caveat from the options-flow study applies here too.

## What this does and does not rule out

- **Rules out:** these six simple, day-level aggregate FII/DII/Client
  positioning features predicting NIFTY's 5-day forward return, at the
  fixed bar this project has used throughout.
- **Does not rule out:** a longer history (this NSE archive very likely
  extends further back than this project's 2-year option-chain window —
  worth fetching more years given the data source is already built and
  cached), a different horizon, isolating DII net positioning specifically
  rather than as one of six features, or combining this with the
  technical/options-flow features already tested (a joint model was not
  tried — each information source was tested in isolation, by design, to
  keep each result interpretable on its own).
- **Does not test SENSEX** — the underlying NSE archive covers the whole
  market's participant positioning, so this data source has no
  underlying-specific limitation, but SENSEX's own option-chain history
  (for the label side of the study) is still accumulating.

## Five independent studies, five negative verdicts

| Study | Method | Result |
|---|---|---|
| `chain_replay.py` | Trade-level replay, full signal engine | Direction correct 32.9% of 85 real trades |
| `direction_predictability_study.py` | ML on price-action technicals | 0 of 8 folds beat chance |
| `options_flow_predictability_study.py` | ML on PCR/OI-change features | 0 of 7 folds beat chance |
| `max_pain_pinning_study.py` | Max pain vs. spot, expiry-day pinning | Loses to naive spot baseline everywhere |
| `fii_dii_positioning_study.py` (this one) | ML on FII/DII/Client positioning | 1 of 7 folds beat chance — closest yet, still fails |
