# Predictive-value study: does options-flow (PCR, OI change) predict NIFTY's forward return?

Generated by `research/ml/options_flow_predictability_study.py`. Full
output: `options_flow_predictability_NIFTY.json`.

## Context: the one genuinely untested angle

`direction_predictability_study.py` tested pure price-action technical
features (RSI, MACD, ADX, Bollinger bands, ATR, realized volatility) and
found no exploitable signal — 0 of 8 walk-forward folds beat chance. That
study never touched the options chain itself. Options-flow features
(put-call ratio, open-interest change) are a genuinely different
information source, computable **right now** from the 20.8M strike rows
already sitting in `data/option_chains.db` — no new data collection
needed.

Six features, all derived from OI/volume already in the recorded chains:
`pcr_oi`, `pcr_volume` (put-call ratio by open interest and by volume),
`call_oi_change_1d`, `put_oi_change_1d`, `total_oi_change_1d`,
`pcr_oi_change_1d` (day-over-day changes). Same discipline as the earlier
study: leakage-safe (each day's features use only that day and earlier),
purged walk-forward validation, two standard classifiers
(LogisticRegression, RandomForest), verdict compared against each fold's
own majority-class baseline.

## A real bug found and fixed while building this

The dataset builder returned zero rows on the first run: chain IDs pulled
from a pandas groupby came back as `numpy.int64`, and passing those as
SQLite query parameters **silently returns zero matching rows rather than
raising an error or coercing the type** — confirmed directly. Fixed by
casting to plain Python `int` before binding. Worth flagging generally:
this is a real footgun for any future code passing pandas-derived values
as sqlite3 parameters in this codebase.

| Worst single fold accuracy | 26.3% (fold 3) |
| Folds beating their own majority baseline | 3 of 7 |

Zero of seven folds cleared the bar. This is the **third independent
line of evidence**, using three different methods on the same real NIFTY
data, all agreeing:

| Method | Result |
|---|---|
| Trade-level replay through the full signal engine (`chain_replay.py`) | Direction correct 32.9% of 85 real trades |
| ML on price-action technical features (`direction_predictability_study.py`) | 0 of 8 walk-forward folds beat chance |
| ML on options-flow features (this study) | 0 of 7 walk-forward folds beat chance |

Feature importance (RandomForest) ranked `pcr_oi` highest (24.7% of total
importance), but "highest-ranked among features that collectively don't
work" is not evidence of anything — no fold reached the accuracy gate
regardless of which feature dominated.

## An honest limitation: daily, not intraday, sample size

Options-flow features are inherently daily — open interest changes day to
day, not meaningfully minute to minute — so this study has one observation
per trading day (348 total) versus the technical study's one observation
per 15-minute bar (~8,600 total). Each fold here has ~38 test days versus
~936 test bars in the technical study. This is a real, disclosed
limitation: a daily signal simply cannot be tested with as many
independent observations as an intraday one on the same 2-year window. It
does not by itself explain the negative result (folds are uniformly weak,
several dramatically below their own baseline, not just "noisy near the
gate"), but it does mean this verdict carries less statistical weight per
fold than the technical study's, and is worth re-running once significantly
more daily history accumulates.

## What this does and does not rule out

- **Rules out:** simple, aggregate PCR and OI-change features predicting
  NIFTY's 5-day forward return on this data. Two different feature
  families (price-action technicals, options-flow aggregates) and two
  different measurement methods (trade-level replay, walk-forward ML) all
  agree independently.
- **Does not rule out:** more sophisticated options-flow features not
  built here — max pain, IV skew, strike-level OI concentration near spot,
  Greeks-weighted flow — or a different horizon than 5 days. None were
  tested; none should be assumed to fail just because these six simple
  aggregates did.
- **Does not test SENSEX** — no recorded chain history exists yet for it
  (recorder now running, still accumulating).

## Recommendation

With three independent negative results on the same real data, further
iteration on rule-based or simple-ML direction prediction for NIFTY at
this timeframe has a low expected return relative to the effort. The
remaining open, genuinely different paths are the ones already identified
across the prior findings docs: real 30-45 DTE history for a properly
time-boxed, actively-managed Iron Condor, or a fundamental reconsideration
of what this account should be trying to do. This is the point to have
that conversation with the user rather than run a fourth variation of the
same test.
